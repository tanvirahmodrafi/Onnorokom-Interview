# Frontend

React 19 + Vite + TypeScript + Tailwind / shadcn UI for the School Admission System.
See the [root README](../README.md) for running everything with Docker.

```bash
cp .env.example .env    # VITE_API_URL=http://localhost:8080
pnpm install
pnpm dev                # http://localhost:5173
pnpm test               # Vitest + Testing Library
pnpm build              # type-check + production bundle
```
